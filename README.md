# Dog vs Cat Image Classification using CNN

This project is a Convolutional Neural Network (CNN) based image classification
system that predicts whether an image contains a **Dog** or a **Cat**.

## Project Overview
- Dataset contains images of dogs and cats
- Images are resized to 150x150
- CNN model is trained using TensorFlow & Keras
- Model predicts class of a given image

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
